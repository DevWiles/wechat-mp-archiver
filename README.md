# wechat-mp-archiver

把一个微信公众号的**全部历史文章**批量保存成 Markdown 笔记，适合直接放进 Obsidian 等本地知识库。

## 功能

- **自动滚动**：在微信电脑版的公众号主页上模拟手动滚轮，把历史文章一路加载到底
- **提取文章链接**：只读扫描微信进程内存，挑出目标公众号的全部文章链接
- **抓取正文**：转成干净的 Markdown，自动去掉「点击上方关注」之类的模板文字；支持普通图文、图片消息、活动类文章
- **图片本地化**：图片下载到 `attachments/`，笔记里用相对路径引用，离线也能看
- **元数据 + 索引**：每篇带 YAML frontmatter（标题、公众号、作者、日期、原文链接），并生成按日期倒序的索引
- **断点续抓**：随时可以中断，再次运行自动跳过已完成的文章
- **防风控**：请求间隔带随机抖动；连续遇到「环境异常 / 验证码」会自动停止

## 环境要求

- Windows 10 / 11（滚动和扫描链接依赖 Windows API；抓取正文跨平台）
- JDK 17+、Maven
- 微信电脑版

## 快速开始

1. 在微信电脑版里打开目标公众号的主页
2. 双击 **`run.bat`**，按提示一路回车（首次运行会自动编译）
3. 看到「回车后，切到微信公众号主页……」时按回车，把鼠标移到微信的文章列表上**别动**
4. 鼠标静止 3 秒后开始自动滚动；滚到底后自动扫描链接并开始抓取正文

运行中**动一下鼠标**就会停止滚动，可选择重试、改为手动滚或退出。Git Bash 用户也可以运行 `./run.sh`。

## 分步使用

```bash
mvn -q package        # 编译，产物 target/wx-archiver.jar
```

**0. 获取公众号的 biz**：浏览器打开该号任意一篇文章，查看网页源码，找到 `var biz = "Mzg3ODIwNDg5OA=="`。

**1. 滚到底并扫描链接**：在微信电脑版打开该公众号主页，运行后把鼠标停在文章列表上：

```bash
java -jar target/wx-archiver.jar scroll --biz "Mzg3ODIwNDg5OA==" --out urls.txt
```

滚动节奏模仿手指拨滚轮：每一下拨半圈（9–13 格），停 0.6–1.5 秒等加载，每 6–12 下歇 3–8 秒，偶尔往回拨几格。
画面连续多下不再变化即判定到底，时长上限默认 40 分钟（`--minutes` 可调）。

也可以自己手动滚到底，再单独扫描：

```bash
java -jar target/wx-archiver.jar scan --biz "Mzg3ODIwNDg5OA==" --out urls.txt
```

**2. 抓取正文**：

```bash
java -jar target/wx-archiver.jar fetch --biz "Mzg3ODIwNDg5OA==" --urls urls.txt \
     --out "F:/Documents/Obsidian Vault/公众号/韩数同学" --delay 3
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--delay` | 3 | 每篇间隔秒数（带 ±30% 随机抖动）。别调太小，容易触发风控 |
| `--images` | local | `local` 下载到 `attachments/`；`remote` 保留外链；`none` 去掉图片 |
| `--limit` | 不限 | 本次最多新增多少篇，适合分批跑 |

## 输出

```
<输出目录>/
├── 00-索引.md                 按日期倒序的文章索引
├── 2026-10-15 <标题>.md        每篇一个笔记
├── attachments/               本地化的图片
├── urls.txt                   文章链接清单（一键运行时生成）
└── .archiver-state.tsv        断点记录
```

笔记的 frontmatter 示例：

## 安全设计

| 设计 | 实现位置 |
|---|---|
| 只发 GET 请求，没有任何上传 | `SafeHttp.java`（全项目唯一的出网口） |
| 域名白名单：页面只访问 `mp.weixin.qq.com`，图片只访问微信图床；重定向逐跳校验 | `SafeHttp.java` |
| 读取微信内存只用只读权限，不写、不注入 | `MemoryScanner.java` |
| 内存内容不落盘，只输出目标公众号的文章链接 | `LinkExtractor.java` |
| 自动滚动只发滚轮事件，不点击、不输入；鼠标下不是微信窗口不滚，动鼠标即停 | `AutoScroller.java` |
| 不删除任何文件 | — |
| 依赖仅 jsoup、JNA | `pom.xml` |

## 常见问题

**只抓到二十来篇？** 主页没滚到底。重新运行，在「已有链接清单，直接复用？」处输入 `n`，重新滚动扫描即可，已抓过的文章会自动跳过。

**出现「操作频繁」或抓取提示风控？** 微信限流了，过几小时再运行，会从断点继续。可以适当调大 `--delay`。

**有些笔记没有图片？** 部分文章原文就是纯文字。非微信图床的外链图片会保留原链接，不会下载。
